# Data Intelligence Reporting Specialist @ Nextcare Allianz Partners Case Study

## Description
This project delivers comprehensive analytics within the health insurance domain, with a specific focus on claims and policy performance.

It analyzes two years of medical claims data (AED 51.3M across 105K claim lines) and nine days of helpline call center data (37K calls) to uncover cost drivers, operational bottlenecks, and actionable business recommendations.

The repository is structured into three distinct branches, featuring interactive Power BI dashboards and optimized SQL queries against a relational database schema.
